
# My First Website

Website portofolio sederhana untuk latihan menjadi web developer.

## Bagian Website

1. **Home** — perkenalan singkat.
2. **About** — penjelasan tentang diri dan proses belajar.
3. **Projects** — contoh proyek yang pernah dibuat.

## Teknologi yang Digunakan

- HTML untuk membuat struktur website.
- CSS untuk mengatur warna, ukuran, jarak, dan tata letak.
- JavaScript untuk membuat tombol interaktif dan menampilkan tahun otomatis.

## Cara Menjalankan Website

1. Buka folder proyek di Visual Studio Code.
2. Buka file `index.html`.
3. Klik kanan pada file tersebut.
4. Pilih **Open with Live Server**.

## Cara Mengubah Isi Website

- Buka `index.html` untuk mengganti nama, deskripsi, dan daftar proyek.
- Buka `style.css` untuk mengganti warna dan tampilan.
- Buka `script.js` untuk mengubah fungsi tombol.

Selamat belajar!
